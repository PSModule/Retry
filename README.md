# Retry

Retry is a PowerShell module for running script blocks with retry behavior.

## Installation

Install the module from the PowerShell Gallery:

```powershell
Install-PSResource -Name Retry
Import-Module -Name Retry
```

## Documentation

Documentation is published at [psmodule.io/Retry](https://psmodule.io/Retry/).

Use PowerShell help and command discovery for module details:

```powershell
Get-Command -Module Retry
Get-Help <CommandName> -Examples
```
